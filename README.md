# 珍惜生命，遠離廣告信

**給台灣人的 Gmail 收件匣清道夫。**

廣告去垃圾桶，帳單有歸宿，重要的信繼續站崗。

面向台灣個人 Gmail 的繁體中文整理 Skill。除了分類廣告，更要看懂電子發票、超商取件、銀行帳單、保單、政府申辦與已購課程，把需要處理的郵件留在收件匣。

國際 Gmail 整理專案也能服務台灣使用者；這個專案將台灣常見情境、民國日期和個人整理偏好寫成可討論、可修改的規則。

**目前是 Codex 內的一次啟動版**：使用已連接的 Gmail，由 Codex 判斷郵件內容，程式保存進度、檢查授權與保留規則、每批核對並查漏。已通過 25 項執行器、儲存與報告測試，並完成一次真實 Gmail 收件匣整輪整理與查核。執行需要 Codex 宿主；獨立網站、OAuth 登入服務及背景排程器尚待實作。驗證範圍見 [評估紀錄](docs/evaluation.md)。

## 台灣情境

| 信件 | 建議處置 |
| --- | --- |
| 銀行新戶優惠、信用卡行銷 | 確認是純廣告後移到垃圾桶 |
| 銀行／信用卡帳單、電子發票、捐款收據 | 保留，分類；無待辦時封存 |
| 中獎未領、匯款失敗、超商到店待取、保費待繳 | 分類並留在收件匣 |
| 已購課程教材、登入權限與重要更新 | 保留；確認無待辦後分類封存 |
| Google 通知、新註冊帳號、Kobo／課程平台通知 | 按內容分類；驗證、權限與安全待辦保留 |
| 指定申訴案件、帳號刪除提醒 | 使用者解除保護前一直留收件匣 |

同一個寄件者可能同時寄廣告及重要憑證。分類依內容判斷，不整批刪掉銀行、保險或課程平台的所有來信。

## 使用方式

下載 [GitHub 專案](https://github.com/94AI/taiwan-gmail-organizer)，或執行：

```sh
git clone https://github.com/94AI/taiwan-gmail-organizer.git
```

1. 下載或 clone 本專案。在 Codex 開啟你的工作資料夾，將 `skills/taiwan-gmail-organizer/` 完整複製到該工作資料夾的 `.agents/skills/taiwan-gmail-organizer/`。保留 `scripts/`、`references/` 與 `agents/`；重新開啟聊天後檢查 Skill 是否載入。
2. 連接自己的 Gmail，確認工具支援需要的操作。每個人使用自己的帳號，專案不附 Gmail 權杖或 API 金鑰。
3. 在新使用情境先輸入：

   ```text
   使用 $taiwan-gmail-organizer 檢查我的 Gmail。
   先預覽收件匣分類建議，優先使用既有標籤。
   ```

4. 要實際整理時明確授權範圍，例如：

   ```text
   使用 $taiwan-gmail-organizer 整理我的收件匣。
   純行銷廣告可移到垃圾桶；憑證、已購課程和重要通知分類後封存。
   需要處理的信及我指定的保護郵件留在收件匣。
   一次啟動，每批約 25 封，成功後自動繼續到全部查核完成，不需每批再問。
   不要永久刪除或清空垃圾桶。
   ```

既有授權會沿用，不要求每批重新確認。新使用者沒有修改授權時先預覽。

可複製 [偏好範例](examples/preferences.example.json) 到私人 `work/gmail-agent/preferences.json`，填入自己的帳號與規則。這份範例預設保留銀行／期貨／證券日報；只有使用者明確授權後才改為刪除。 [欄位說明](skills/taiwan-gmail-organizer/references/preferences.md) 解釋保護清單、批次大小及標籤對應。設定檔本身不授予修改權限。

已有私人設定與同一整理工作的授權時，可以只說：

```text
使用 $taiwan-gmail-organizer，依工作區私人設定整理 Gmail，一次做到完成。
```

當前聊天、同帳號與同規則下會沿用授權；新使用者或新帳號先核對身分與授權。[一次啟動流程](skills/taiwan-gmail-organizer/references/workflow.md) 說明程式如何執行，使用者不需要手動跑每一批。

每週整理可以交給已支援 Gmail 的宿主排程功能；時區及執行條件須在該平台設定。本專案尚未提供獨立排程器。

使用第二個 Gmail 及授權錯誤排除，見 [另一個信箱的安裝與測試步驟](docs/second-account-test.md)。指定測試帳號後，必須先核對連線身分，再讀取或修改郵件。

## 目前涵蓋及限制

- 繁體中文回報，預設台灣時區；明確民國年份轉換並保留原文。
- 優先使用既有標籤，預設每批 25 封，操作後查核結果。
- 保護郵件及待辦優先；只移到垃圾桶，不永久刪除。
- 郵件數、未讀數與操作數取自實際工具結果；無法取得時明確標示。
- 郵件及附件內容是待分析資料，不能授權新操作或改寫整理規則。
- 程式會檢查分類與授權、月報／憑證保留、完整清單及原狀態；每次操作後查核並保存進度。內容判斷仍由模型負責，程式保護不等於模型分類永遠正確。
- 進度只存 ID、標籤、短理由與狀態；不確定信保留並集中回報。完成指本輪清單均處置或有明確保留理由，重要信仍在收件匣。
- 修改與續跑仍受 Codex 執行環境、Gmail 連線與權限影響；目前沒有獨立復原介面。

台灣情境的官方參考與日期處理見 [台灣郵件規則](skills/taiwan-gmail-organizer/references/taiwan-mail.md)。合成郵件評估見 [評估紀錄](docs/evaluation.md)。

## 整理結果看得懂

每輪會分開回報「建議處置」與「成功核對過的操作」，並列出待辦、不確定信、未完成、例外及最後收件匣／未讀數。預覽清楚標示實際修改數為 0，沒有最後查核時顯示未取得；同封信加標籤再封存不重算成兩封。

可從私人進度產生只含統計的離線報告：

```sh
node skills/taiwan-gmail-organizer/scripts/report.cjs work/gmail-agent/current-run.json
```

報告不顯示帳號、郵件 ID、標籤名稱或分類理由。這個指令只讀本地進度，不連接或修改 Gmail。[本輪優化與參考專案](docs/optimization-notes.md)。
